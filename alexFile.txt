/***************************************/
 How to setup Prettier, ESLint, and Husky in my project?
/***************************************/

1.  Install the necessary dependencies:

npm install --save-dev prettier eslint husky lint-staged

2.  Configure Prettier: Create a .prettierrc file in the root of your project with the following content:
{
  "semi": true,
  "singleQuote": true,
  "trailingComma": "all",
  "printWidth": 80
}

3.Configure ESLint: Update your eslint.config.js to include Prettier:

import js from '@eslint/js';
import globals from 'globals';
import reactHooks from 'eslint-plugin-react-hooks';
import reactRefresh from 'eslint-plugin-react-refresh';
import tseslint from 'typescript-eslint';
import prettier from 'eslint-config-prettier';

export default tseslint.config(
  { ignores: ['dist'] },
  {
    extends: [
      js.configs.recommended,
      ...tseslint.configs.recommended,
      'plugin:prettier/recommended',
    ],
    files: ['**/*.{ts,tsx}'],
    languageOptions: {
      ecmaVersion: 2020,
      globals: globals.browser,
    },
    plugins: {
      'react-hooks': reactHooks,
      'react-refresh': reactRefresh,
    },
    rules: {
      ...reactHooks.configs.recommended.rules,
      'react-refresh/only-export-components': [
        'warn',
        { allowConstantExport: true },
      ],
    },
  },
);

4. Configure Husky: Initialize Husky and add a pre-commit hook:

npx husky install (deprecated)

yarn add --dev husky


5.Configure lint-staged: Add the following configuration to your package.json:

"lint-staged": {
  "*.{js,jsx,ts,tsx}": [
    "eslint --fix",
    "prettier --write"
  ]
}

5.1 Init Husky

npx husky init

6. Delete de command  in husky/pre-commit

npm test

7. Install Storybook with yarn
 
npx storybook@latest init --builder vite

/***************************************/
How to install Jest 2025?
/***************************************/

1. Install these dependencies in the development environment

yarn add -D jest @types/jest ts-jest  
yarn add -D @tailwindcss/postcss
yarn add -D babel-jest @babel/core @babel/preset-env @babel/preset-react @babel/preset-typescript identity-obj-proxy

2. Create jest.config.ts whith this configuration

import type { Config } from 'jest';

const config: Config = {
  preset: 'ts-jest',
  testEnvironment: 'jsdom',
  transform: {
    '^.+\\.(ts|tsx|js|jsx)$': 'babel-jest',
  },
  moduleNameMapper: {
    '\\.(css|less|scss|sass)$': 'identity-obj-proxy',
  },
  transformIgnorePatterns: ['/node_modules/(?!(nanoid|other-esm-package)/)'],
  moduleFileExtensions: ['ts', 'tsx', 'js', 'jsx', 'json', 'node'],
};

export default config;

3. Create babel.config.js whith this configuration

module.exports = {
  presets: [
    ['@babel/preset-env', { targets: { node: 'current' } }],
    ["@babel/preset-react", {
      "runtime": "automatic"
   }],
    '@babel/preset-typescript',
  ],
};

4. Create postcss.config.js whith this configuration

module.exports = {
    plugins: {
      '@tailwindcss/postcss': {},
      autoprefixer: {},
    },
  };

EXTRA: Usefull commands

yarn jest --clearCache
touch postcss.config.js
